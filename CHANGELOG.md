# Changelog

All notable changes to Football Score Lite will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-25

### Added
- Initial release of Football Score Lite
- Match management system with team lineups and officials
- Live score bug with real-time updates
- Lower third graphics for player information
- Breaking news banner
- News ticker for scrolling updates
- Graphics customization system with patterns and colors
- WebSocket-based synchronization across renderer windows
- PixiJS v8 graphics rendering engine
- Electron desktop application
- Dark theme UI with modern design
- CSV import for players and officials
- Multi-sport support (Football and Futsal)
- Tournament and fixture management
- Commentator view for match information
- Graphics output for OBS integration
- Local data persistence using Dexie.js
- Keyboard shortcuts for common actions
- Auto-save functionality
- Match event timeline
- Statistics tracking

### Features
- **Score Bug**: Live match score with timer, team logos, and extra time
- **Lower Third**: Player name and information overlay
- **Ticker**: Scrolling news and match updates
- **Breaking Banner**: Full-width breaking news display
- **Versus Screen**: Pre-match team comparison
- **Starting Lineup**: Team lineups with formations
- **Substitution Overlay**: Player substitution graphics
- **Match Officials**: Referee and officials information
- **Event Overlay**: Goal, card, and other match events

### Technical
- Built with React 19, Next.js 16, and TypeScript
- Electron 31 for desktop application
- PixiJS v8 for hardware-accelerated graphics
- Tailwind CSS for styling
- Zustand for state management
- WebSocket server for real-time sync
- IndexedDB for local storage
